## 一、十条决策（定稿）

| # | 决策项 | 定稿结论 | 一句话理由 | 推翻成本 |
|---|---|---|---|---|
| D1 | 主用户 | **现场帮助者**（网格员 / 大堂经理 / 导诊） | "老人不会截图"这个矛盾直接消失 | 高 |
| D2 | 老人端 | **不做独立页面**，改帮助者端全屏模式 | 现场是双屏，帮助者手机就是展示端 | 中 |
| D3 | 子女远程场景 | **封存，本赛期不做** | 依赖分享链接 → 依赖备案 → 引入不确定性 | 低 |
| D4 | 定位方案 | OCR + LLM 选目标；VLM 只兜底图标 | 延迟 2–3s vs 5–8s，成本低一个量级 | 高 |
| D5 | 图标类 | 锚点 + 偏移，画大区域，不追精确框 | 首个典型任务第一步就会撞上 | 低 |
| D6 | 置信度 | 三信号：top1/top2 分差 + 3 次采样一致性 + 检索强度 | LLM 自报值不校准，答辩会被问穿 | 低 |
| D7 | RAG 用途 | **多步流程预热**，不是检索答案 | 否则就是"为 6% 硬塞" | 中 |
| D8 | 多步流程 | 最多**连续 2 步**，不做长链路 | 控制状态机复杂度 | 低 |
| D9 | 评测 | gate 50 张 / 文档 100 张；hit@1 = 预测框中心落在真值框内 | 30 张的 CI 是 ±13pp，测不出 85% | 低 |
| D10 | 技术栈 | Vue3 + Vite + TS + Tailwind 3.4 + shadcn-vue；FastAPI + LangGraph + Chroma + SQLite | 复用 devSage，不换栈 | 中 |

## 三、技术栈冻结

| 层 | 锁定 | 版本策略 |
|---|---|---|
| 前端框架 | Vue 3 + Vite + TypeScript | 锁 major，不追最新 |
| 样式 | **Tailwind 3.4** + shadcn-vue | **禁止升 4.x**（配置不兼容） |
| 状态 / 路由 | Pinia + Vue Router | — |
| 后端 | FastAPI + uvicorn | — |
| Agent | LangGraph（自定义 StateGraph） | 复用 devSage |
| 向量库 | Chroma | 只存文档向量，不存截图 |
| 检索 | jieba BM25 + 云端 embedding + 云端 rerank | **本地不加载 torch** |
| OCR | RapidOCR（onnxruntime，CPU） | 本地，截图不外传 |
| 主 LLM | DeepSeek | 文本选择 + 文案生成 |
| VLM 兜底 | Qwen-VL / 豆包 vision | 仅图标场景 |
| MCP | fastmcp | 4 个工具 |
| 数据库 | SQLite | 截图 7 天自动清理 |
| 部署 | Docker Compose + Nginx 同域反代 | 避免 CORS |

**明确不用**：RabbitMQ、Redis、Nuxt、Next.js、Postgres、微信登录。
