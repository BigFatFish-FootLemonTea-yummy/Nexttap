## 四、域外拒识（返工新增）

初版 hybrid 模式直接丢掉了 `min_score` 过滤，导致：

```
"我想买火车票"  -> 返回 3 条，分数全是 RRF 地板分 0.016
"今天天气怎么样" -> 返回 3 条，全是地板分
```

连带 MCP 的 `search_guide` 里 `"" if hits else "没有匹配到标准路径"` 永久失效。

**返工过程（三轮，值得记录）**：

| 轮次 | 方案 | 结果 |
|---|---|---|
| 1 | 向量相似度 >= 0.45 | 域外仍误召 3/8。「我要打游戏」→ map.taxi 0.524，比正确的「给孙子点零花钱」0.535 只低 0.011 |
| 2 | 加「字面必须有交集」硬门槛 | 域外 0/8，但**砍掉 14 条正确答案**（「给他转点钱」→转账 0.770 都被砍） |
| 3 | **绝对阈值 + 相对领先** | 域外 0/8，原集 79.4%，留出集 71.2% ✅ |

第三轮的判据：

```python
top_sim >= 0.55  and  (top1 - top5) >= 0.02
```

**为什么这样有效**：域外查询的问题不是分数低，而是**分数平**——
一堆 0.41–0.53 挤在一起，说明模型对这句话没有任何偏好，就该拒识。
域内查询通常 top1 明显领先。

参数可调：`NEXTTAP_VECTOR_MIN` / `NEXTTAP_VECTOR_GAP`。
调参曲线（域外误召 / 原集 / 留出集）：

| MIN | GAP | 域外误召 | 原集 R@5 | 留出 R@5 |
|---|---|---|---|---|
| 0.50 | 0.02 | 3/8 | 80.9% | 76.9% |
| 0.50 | 0.05 | 1/8 | 76.5% | 75.0% |
| **0.55** | **0.02** | **0/8** | **79.4%** | **71.2%** |
| 0.55 | 0.05 | 0/8 | 76.5% | 71.2% |
| 0.60 | 0.02 | 0/8 | 73.5% | 63.5% |

选了 0.55/0.02：域外全拒，召回损失最小。

## 五、技术路线

### 为什么用本地 ONNX 而不是云端

原计划走云端 embedding（技术文档 2.3 就是这么写的），但：

- DeepSeek 的 key **调不通**智谱/通义的 embedding 接口（服务商不同，401）
- 评审意见 §三 建议「embedding + rerank 换 onnxruntime 后端，内存可砍一半」

**实际：`fastembed` + `BAAI/bge-small-zh-v1.5`（512 维，ONNX，约 90MB）**

> ⚠️ **技术文档 2.3 写的「Embedding 上云」与实现矛盾，需要改。**

### 三阶检索

```
query
  ├─ 词面召回（_score）：去填充词 + 同义词扩展 + 二字组重合度
  ├─ 向量召回（_VectorIndex）：bge-small-zh 余弦相似度
  ├─ 域外拒识：绝对阈值 + 相对领先
  ├─ RRF 融合：score = Σ 1/(60+rank)
  └─ rerank（可选，仅离线）
```

**为什么用 RRF**：词面是 0–1 相似度、向量是余弦距离，量纲不同，
直接加权要归一化且权重难调；RRF 只看排名，无需调参。

### 开关与降级

| `NEXTTAP_RETRIEVAL` | 行为 |
|---|---|
| `lexical` | 只走词面 |
| `hybrid` | 词面 + 向量 + RRF（**默认，线上用这个**） |
| `hybrid_rerank` | 再叠 rerank（离线消融用） |

`fastembed` 缺失或加载失败 → 自动退回纯词面，不抛异常（已模拟 ImportError 验证）。
